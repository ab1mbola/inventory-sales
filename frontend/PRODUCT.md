# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React 19, Vite 8, Tailwind CSS v4, Zustand, TanStack Query 5, Lucide React, ApexCharts

## Users
Retail store cashiers, shop managers, and SMB owners managing multi-tenant store operations.

## Product Purpose
Mnemos is a multi-tenant inventory and sales tracking terminal that provides real-time transaction records, POS cart checkout, and store credit tracking without complex deployment overhead.

## Positioning
A secure, real-time, multi-branch memory bank for retail transactions that keeps store operations clear, secure, and accurate for small-to-medium businesses.

## Operating Context
Fast-paced retail environments requiring rapid item searching, quick checkout, credit payment recording, and clear visual feedback for busy retail cashiers.

## Capabilities and Constraints
* Multi-tenant data isolation.
* Real-time POS checkout with cart management.
* Inventory tracking (products and categories).
* Customer profiles and store credit/payment logs.
* Sales reporting and analytics.

## Brand Commitments
* Name: Mnemos
* Tone: Bright, energetic, and highly readable.
* Aesthetics: Friendly rounded corners and high-energy highlights.
* Typography: Clean, minimalist sans-serif throughout (e.g., Inter or system sans-serif) for maximum readability and speed.

## Evidence on Hand
An existing full-stack React + Express implementation is functional but has inconsistent visuals and uses serif fonts.

## Product Principles
1. **Utility First:** Fast scanning and checkout operations are paramount.
2. **Absolute Clarity:** Clean, high-legibility typography with zero visual clutter.
3. **Warmth & Energy:** Energetic color highlights and friendly rounded corners.
4. **Reliable Memory:** Immediate, clear visual feedback for every transaction.
